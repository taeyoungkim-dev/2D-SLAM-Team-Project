해당 문제를 해결하기 위해 다음과 같은 시도를 했습니다.

### `GAZEBO_MODEL_PATH` 강제 주입
리소스 경로 탐색 문제인지 확인하기 위해 터미널에서 launch 파일을 실행하기 직전에 환경 변수를 수동으로 Export해보았습니다.

```zsh
# Custom 패키지의 models 디렉토리를 Gazebo 모델 경로에 추가
export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:/root/ros2_slam_ws/2D-SLAM-Team-Project/src/custom_burger/models

# 다시 시뮬레이터 실행
ros2 launch custom_burger my_house.launch.py
```

그러나, 여전히 exit code 1이 발생하였습니다.
